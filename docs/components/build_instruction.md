# Componentes – Build Instruction

## Objetivo
Definir componentes reutilizáveis (p. ex., tabela, modal). O Core não inclui Sidebar como componente padrão.

## Contrato geral de componentes
- Props documentadas
- Estilos compatíveis com temas (tokens de cor)
- Slots/áreas para ações (editar inline, botões)

Futuro: editor de CSS modular.
