# Documentação – UI Standards (UI v7)

## Temas
- **VS Code (Dark)** – tema padrão.
- **WhatsApp (Light)** – tema claro.

## Ícones
- Família **Codicons** (VS Code). Consistência de ícones por ação.

## ActivityBar
- Ícones 25px, indicador lateral (azul no dark; preto no light), botão **Sair** no rodapé.
- Ordem: módulos fixos → opcionais; usuário pode reordenar.

## Edição Inline
- Label cinza, valor azul, input sem borda em foco, salvar em blur/Enter, confirmação via toast leve.

## Modais & Toasts
- Modais leves, não bloqueantes; toasts curtos na base central.
