# Padrões de UI (v7)

## Temas
- **VS Code (Dark)** – tema padrão inicial.
- **WhatsApp (Light)** – tema claro; fonte compacta; tons de cinza.

## Ícones
- Codicons (estilo VS Code). Ícones coerentes por ação: gear (prefs), shield (admin), power (sair), sun/moon/vscode (temas).

## ActivityBar
- Ícones de 25px, indicador lateral, botão Sair no rodapé. Ordem por `order desc`, com override do usuário.

## Edição Inline
- Valor clicável vira input sem borda; blur/Enter salva; toast confirma.

## Toasts
- Leves, em bolha, na parte inferior central; sumiço automático em ~1.5s.
